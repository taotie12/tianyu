# SZ1 三值排班二维码协议 v1

二维码存放文本，无需网址、账号或服务器。可直接接受 JSON 或带 `SZ1:` 前缀的 JSON：

```text
SZ1:{"v":1,"team":"三值","start":"2026-01-01","days":"TDANOO","tz":"Asia/Shanghai"}
```

此例依次表示 1 月 1 日培训、2 日早班、3 日中班、4 日夜班、5–6 日休息。

| 字段 | 含义 |
| --- | --- |
| v | 必须是数字 1 |
| team | 必须是“三值”，其他值组拒绝导入 |
| start | 有效起始日期 YYYY-MM-DD，2000–2099 年 |
| days | 从起始日期连续每日一个字符，1–400 天 |
| tz | 固定 Asia/Shanghai |

班次编码：`D` 早班，`A` 中班，`N` 夜班，`O` 休息，`T` 培训。大写、不含空格。起始日后的日历日期由软件递增，跨月、跨年和闰年自动处理。结束日也必须在 2099 年内。一次不超过 400 天，较长排班按年拆分。

二维码不提供可信身份认证，不含人员姓名和联系方式，也不携带可执行脚本。只接受此白名单数据结构；数据在用户预览并确认后生效。覆盖仅限导入范围；导入不改变本机班次时间和提前提醒设置。闹钟开启时重新安排闹钟，失败时关闭提醒状态并说明原因，不把失败当作已启用。

上下班时间不从 AI 二维码接收，避免 AI 猜错导致误提醒。使用者必须在软件里确认。夜班日期代表上班开始当天，00:00 是当天零点。

## 上夜、下夜与原始数据

仍使用五种原始编码，兼容 v1.0 的二维码。“休”后面紧接实际夜班时，该“休”日期显示“上夜”，当晚赶班车去上次日零点的班；连续 N 的最后一天在后一天排班已知且不是 N 时显示“下夜”。显示标注不改变原表，不多算一班。缺少相邻日期时不猜测下夜。

以 2026-10-19 起的 `AAONNO` 为例：19 中、20 中、21 上夜、22 夜班、23 下夜、24 休息。21 日 22:10 和 22 日 22:10 有夜班班车，23 日晚上没有。原始二维码编码仍是 AAONNO。

## 新人操作步骤

1. 打开软件首页的「复制 AI 提示词」，复制下方完整文字。
2. 打开支持 Excel 附件的 AI，同时发送原表附件和完整提示词。
3. 核对值组、起止日期和天数，再保存真实可解码的二维码图片。
4. 同一部手机上操作：回到软件 → 扫码导入 → 从相册识别二维码。二维码在另一块屏幕上时用相机扫描。AI 没有生成图片但返回了完整 SZ1 文字时，用「粘贴内容」导入。
5. 核对预览与覆盖提示，再确认导入。示例不会未经确认直接覆盖排班。

应用内有「真实可扫示例 · 6 天」，可保存图片或点击预览试用。也可下载 [6 天演示二维码](AI导入演示-6天.png)，按上面的相册步骤导入。

## 可以复制给其他 AI 的提示词

请读取我随消息上传的 Excel 倒班表，只提取“三值”列的实际逐日排班。不要推测固定周期，也不要把别的值组混入。

请生成一个真实可扫描的二维码，二维码内容必须是以下格式的纯文本，而不是网址、Markdown 代码块或图片下载地址：
SZ1:{"v":1,"team":"三值","start":"YYYY-MM-DD","days":"...","tz":"Asia/Shanghai"}

字段规则：
1. v 固定为数字 1；team 固定为“三值”；tz 固定为“Asia/Shanghai”。
2. start 是排班第一天，格式 YYYY-MM-DD。days 每个字符对应从 start 起连续一天，必须按真实日期排序，正确处理跨月、跨年和闰年。
3. D=原表“早/早班”，A=原表“中/中班”，N=原表“夜/夜班”，O=原表“休/休息”，T=原表“培训”。只允许这些大写字符，不含空格。
4. 保留原表编码。中→休→夜中的“休”仍编码 O，连续夜班最后一天仍编码 N。软件会自行标注“上夜”和“下夜”，请勿额外新增、平移或删除夜班。
5. 若日期分布在各月份列中，请读取每个日期所在行的“三值”班次；不能把行号当作日期。
6. 每个二维码最多 400 天。超过请按年拆分，日期缺失或读不清时请先指出，不要猜测。上下班、起床和班车时间由软件本机设置，不放进二维码。

请依次提供：
① 起止日期、总天数、各原始班次的数量，供我核对；
② 一行完整的 SZ1 原始文本，方便我复制导入；
③ 用二维码编码库（例如 Python qrcode）生成可下载的二维码 PNG，建议至少 800 像素、纠错级别 M、保留白色边距。请回读二维码，确认解码文本与原始文本逐字一致。不要用绘图模型画二维码。如果不能生成图片，请至少提供正确的一行 SZ1 文本。

格式演示（仅示例，实际日期和内容应来自我的附件）：
SZ1:{"v":1,"team":"三值","start":"2026-10-19","days":"AAONNO","tz":"Asia/Shanghai"}
表示 19日中、20日中、21日原表休（软件显示上夜）、22日夜、23日夜（软件显示下夜）、24日休。
