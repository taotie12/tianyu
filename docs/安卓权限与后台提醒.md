# 锁屏与后台闹钟设置

安装 v1.3 后先打开应用，在右上角三横线 →「闹钟权限与后台设置」逐项检查。提醒页顶部也有同名按钮。需要在你自己的手机上授权，软件不能自动开启。

1. **允许通知**：允许通知、锁屏通知和悬浮通知；「上班闹钟」分类也要允许弹出。响铃用的是手机的**闹钟音量**，不要设为零。
2. **精确闹钟**：在「闹钟和提醒」中允许值日。
3. **全屏提醒**：Android 14 及以上允许全屏通知。旧版本在通知分类中设置锁屏/悬浮显示。
4. **锁屏显示、后台弹出界面**：小米/红米的应用信息 → 权限管理 → 其他权限 → 分别设为允许。不同系统名称可能略有不同。
5. **自启动**：小米/红米的应用信息 → 自启动，开启。华为/荣耀在应用启动管理中允许自启动、关联启动、后台活动；其他品牌检查类似设置。
6. **电池限制**：打开电池优化列表，切换「所有应用」，选择值日，允许忽略优化。再在应用信息 → 省电策略选「不限制」，关闭后台清理。在最近任务中长按值日并锁定/加锁，避免一键清理。

应用能检测通知、精确闹钟、系统全屏通知、通知分类和电池优化状态。锁屏显示、后台弹出、自启动的厂商开关没有通用检测接口；「已自行核对」仅记录你的确认。系统设置入口不适配时会退回应用信息，按上述路径手动设置即可。设置后回到应用会刷新状态，也可点「刷新权限并重试恢复闹钟」。

## 正式使用前实测

- 点「30 秒后测试锁屏与后台响铃」，马上返回桌面并锁屏，检查是否响铃、显示停止/延后按钮。
- 再安排一次测试，尝试平时的一键清理，等待响铃。失败时优先核对自启动、后台弹出、应用锁定和省电策略。
- 查看应用记录的下一次闹钟；重启手机、解锁后等待一次正式提醒，检查重启恢复。
- 测试停止与「延后 10 分钟」，确认手机闹钟音量合适。响铃最多持续 5 分钟。

应用会保存完整计划，最近 64 条交给系统定时触发，之后逐步补齐。普通页面刷新不再清空已有闹钟；同步失败会提示，并保留设置，等待恢复后重试。新设置未同步成功前，手机可能仍按旧计划提醒，请先处理页面上的错误。

**系统「强行停止 / 结束运行」会禁止闹钟，必须重新打开应用。**部分厂商把清后台等同于限制启动，需要按上方设置并实测。记录「最近一次启动响铃」表示服务启动过，不能证明你听到了声音。

更新请直接覆盖安装；卸载、清除应用数据会丢失本机排班和设置。
