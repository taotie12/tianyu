## 导入与更新

二维码可用于 v1.4 或更高版本；[v1.5 安装包](../../downloads/sanzhi-calendar-v1.5.apk)另提供删除班组功能。保存图片后，在软件「导入 → 从相册识别二维码」中选择，核对 **133 天**和班组名称再确认。

名称仍为 **一值（大修中）**、**五值（大修中）**。已经导入旧 126 天版本的用户，无需先删除，再次导入新版会更新同名大修班组并补上前 7 天，不会多出重复班组。重叠日期按新二维码更新；如手动调整过大修排班，请核对导入预览的覆盖提示。

原有“一值”“五值”是独立记录，不受大修二维码影响。确认导入会切换到对应大修班组；闹钟只按当前选中的班组安排，起床、班车时间沿用本机设置。

## 删除班组

v1.5：右上角三横线 →「管理班组」→ 选择班组的「删除」→ 核对名称并确认。删除其他班组不改变当前提醒；删除当前班组会先取消闹钟，再切换剩余班组并关闭提醒，需要时重新开启。最后一个班组也可以删除，重开后保持空日历，可重新导入。删除会移除该班组的本机排班和手动修改。
