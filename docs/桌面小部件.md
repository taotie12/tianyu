# 在安卓桌面查看倒班信息

覆盖安装 [v1.6 安卓安装包](../downloads/sanzhi-calendar-v1.6.apk)，先打开一次应用，让现有排班同步到小部件。不要先卸载，以免丢失本机调整。

## 添加到桌面

1. 在值日右上角三横线菜单打开「桌面小部件」，可预览当前班组的七天排班。
2. 点击「添加到桌面」，在系统弹窗中确认。这个按钮仅在桌面支持直接添加时出现。
3. 如果桌面不支持或没有弹窗，回到桌面，长按空白处；部分手机需双指捏合。
4. 打开「小部件 / 窗口小工具」，找到「值日 · 未来7天排班」，拖到空白位置。建议约 4 × 3 格，长按可调整大小。

网页版提供预览和说明，真正的桌面小部件需要安卓安装版。如果列表没有新小部件，确认已经覆盖安装 v1.6 并打开过应用，关闭桌面编辑后重新进入列表。

## 显示和更新

- 显示当前班组从今天起 7 天的日期、星期和班次。所有小部件都跟随应用中的当前班组；一值至五值、自定义值别及“大修中”班组均适用。
- “休”后接夜班时标为“上夜”，说明今晚班车和次日上班时间；最后一个已确认的夜班标为“下夜”，说明当天早上下班。当下一天排班缺失时，不猜测是否下夜。
- 未包含的日期显示“未排”，不会按周期补排。培训显示培训标签，时间需要在应用内核对。
- 导入、调整、切换班组及删除后同步更新。删除当前班组后显示剩余班组；删除最后一个后显示空状态，避免继续展示已删除的排班。
- 点击卡片打开日历，点卡片右上角刷新图标可从保存的本机排班重新绘制。应用菜单中的「刷新桌面排班」会重新同步应用最新数据。
- 小部件独立保存当前完整排班，在应用未打开时读取后续日期。按北京时间安排次日更新，配合系统每 30 分钟的周期更新；开机、应用更新、修改时间或时区后也会刷新。系统省电可能延迟更新，请以实际手机表现为准。
- 显示小部件不需要通知、精确闹钟或锁屏权限。响铃依旧需要在「提醒」及「闹钟权限与后台设置」单独开启和核对。

## 真机检查

云环境可验证日期规则、排班同步和 APK 构建，不能替代真实安卓桌面。安装后请检查：

1. 添加卡片并调整尺寸，确认七天文字完整；点击卡片和刷新按钮均能工作。
2. 切换已导入的不同值别，修改一天，再导入大修班组，桌面应与应用一致。确认“上夜、下夜”的含义一致。
3. 删除当前班组，再删除最后一个班组，桌面应跟随切换并最终清空；可重新导入恢复。
4. 回到桌面并清理应用后台，检查小部件仍显示。次日查看日期是否更新，重启后再检查；若系统延迟，点右上角刷新。

系统“强行停止”会阻止应用接收更新和闹钟，需重新打开应用。不要将它作为日常关闭方式。长按桌面小部件并移除只会移除卡片，不会删除应用中的班组或排班。
