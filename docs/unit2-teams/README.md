**兼容性：v1.4 已支持任意值别，这四张二维码可以直接扫描或从相册导入，无需重新生成。**请先[下载 v1.4](../../downloads/sanzhi-calendar-v1.4.apk)并覆盖安装，再导入。确认后切换到对应值别，原有三值排班独立保留；首页可切回已保存的值。
