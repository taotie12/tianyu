# 值日 · 倒班日历

作者：**taotie**。支持任意值别的安卓倒班日历，同时提供浏览器版本。首次内置用户上传的《二号机组倒班表》三值实际排班（其他值可通过二维码、文字或 Excel 导入）：2025-12-01 至 2026-12-31，共 396 天。逐日提取，不用周期外推。未包含原表中的人员姓名。

## 安装包下载

[下载安卓测试版 APK](downloads/sanzhi-calendar-v1.7.apk)（进入文件页后点击下载按钮）。[原 Excel 的三值排班二维码](docs/三值排班二维码.png)及[AI 生成格式和提示词](docs/二维码导入协议.md)也已随项目提供。

[OT105 一值、五值大修排班二维码](docs/ot105-overhaul/README.md)：2026-10-19 至 2027-02-28（133 天，包含过渡排班），作为独立“大修中”值别导入，原有一值、五值排班保留。

## 使用

1. 安装 `releases/值日-倒班日历-v1.7.apk`（开发测试签名）；也可运行网页版。
2. 早班 08:00–16:00，中班 16:00–次日00:00，夜班 00:00–08:00。作息已按使用者提供的信息预设；在「提醒」核对起床与班车安排后再开启。培训时间未提供，默认不安排培训闹钟。
3. 在「提醒」或右上角三横线菜单打开「闹钟权限与后台设置」，逐项开启通知、精确闹钟、锁屏显示、后台弹出、自启动，并关闭电池限制。厂商开关需自行核对；完成后点「30 秒后测试锁屏与后台响铃」，返回桌面并锁屏。再分别测试清理后台、重启后的提醒。不要强行停止应用。[详细设置说明](docs/安卓权限与后台提醒.md)。
4. 底部「导入」（桌面版也可用右上角菜单）可打开相机、识别相册二维码、粘贴 SZ1 文本或直接选择同布局的 `.xlsx`。先预览天数、日期及冲突，再确认覆盖。同值别范围外的日期保留；不同值别独立保存并切换显示。
5. 首次使用会显示「AI 排班二维码」提示，点击「已阅读」后隐藏并记住状态。之后从右上角三横线菜单打开「AI 二维码导入教程」，仍可复制提示词、查看步骤和演示二维码。同一部手机可从相册导入，SZ1 文字也能粘贴导入。

## v1.7 两种桌面小部件尺寸

提供 **4×2（从今天起 7 天）** 和 **2×2（从今天起 3 天）**，替换原来的 4×3。右上角三横线 →「桌面小部件」→ 选择尺寸 →「添加到桌面」，在系统弹窗中确认。也可以长按手机桌面空白处 →「小部件 / 窗口小工具」，选择「值日 · 7天排班（4×2）」或「值日 · 3天排班（2×2）」。更新后先打开一次应用；旧 4×3 卡片可长按缩小至两行，或移除卡片后重新添加，不影响排班。

两种尺寸均显示当前班组的日期和班次，自动标注“上夜、下夜”。4×2 下方显示今日作息摘要，2×2 精简为三天班次；点击打开完整日历，右上角可刷新。所有卡片跟随当前选择的班组，自定义值别和“大修中”班组均可使用。

导入、调整、切换和删除后自动同步；删除最后一个班组会清空卡片。小部件独立保存完整排班，在应用未打开时读取后续日期，按北京时间安排跨天刷新，配合系统周期更新和开机恢复。不需要开启闹钟权限；省电可能延迟刷新，可点卡片右上角刷新。未包含的日期显示“未排”，不推算周期。移除一种尺寸不会停止另一种尺寸的更新。

网页版提供尺寸预览，添加功能需使用安卓安装版。[详细说明与真机检查步骤](docs/桌面小部件.md)。

## v1.5 班组删除与完整过渡排班

右上角三横线 →「管理班组」→ 对应班组的「删除」，核对名称后确认。删除其他班组不会影响当前排班或闹钟。删除当前班组会先取消闹钟，成功后切换到剩余班组并关闭提醒；需要提醒时请重新开启。取消失败保留原班组，可重试。如果上次提醒同步尚未完成，会先完成同步再删除；同步失败保留数据并提示。删除最后一个班组后保持空日历，重新打开不会恢复默认三值，可重新导入。

删除会移除所选班组的本机排班和手动调整，其他班组及起床、班车时间保留。删除与保存、前台恢复使用同一队列，避免旧提醒重新出现。

OT105 新版二维码补入 10 月 19–25 日过渡排班，共 133 天。同名“大修中”班组可以直接重新导入更新，无需先删除；原一值、五值仍独立保留。

## v1.4 任意值别

一值、二值、三值、四值、五值及其他值别都能使用。直接扫描以前生成的二维码即可，无需重新生成；首页、分享文件和闹钟会使用真实值别。导入预览明确显示将要切换的值别，确认前不生效。各值排班独立保存在本机，首页标题旁可切换已导入的值，闹钟只提醒当前值。同一个值再次导入时仅更新对应日期，其他值不受影响。

直接读取原布局 Excel 时可从预览中的「Excel 值别」选择相应列。AI 教程第一步可选择或填写任意值别，提示词和示例二维码随之更新。旧版没有值别字段的本机数据自动归入三值，保留用户修改、作息和提醒开关。

[一值、二值、四值、五值全年二维码](docs/unit2-teams/README.md)已兼容本版。二维码仍为 SZ1/v1，没有新格式要求。

## v1.3 弹窗与闹钟修复

所有弹窗使用固定标题栏和独立滚动正文，右上角 × 始终可见，支持手机触摸滚动；安卓侧滑或返回键优先关闭当前弹窗。菜单底部显示「作者：taotie」。

新增锁屏、后台弹出、自启动和电池限制的权限向导、系统设置入口、状态检测与 30 秒测试。厂商专有权限只能手动确认，应用不会假装已授权。闹钟计划同步写入本机；替换失败时尝试恢复旧计划。刷新时恢复原生计划，保留延后闹钟，不再因为临时失败而清空闹钟或关闭提醒；未同步的新设置会标为待重试。重启、更新时间/权限、回到前台时尝试恢复，仍需按自己的手机完成权限与响铃测试。

## 作息与夜班说明

| 班次 | 实际工作时间 | 默认提醒 |
| --- | --- | --- |
| 早班 | 08:00–16:00 | 06:40 起床；07:00 提醒赶 07:10 班车 |
| 中班 | 16:00–次日00:00 | 15:00 提醒赶 15:10 班车 |
| 夜班 | 00:00–08:00 | **前一晚22:00** 提醒赶 **22:10** 班车 |

班车提前量默认 10 分钟，可调整。起床、班车、额外上班前提醒可独立开关，默认不添加重复的上班前提醒。培训需要另行核对时间和开启。

例如 10 月 19–24 日原表为「中、中、休、夜、夜、休」，日历显示「中、中、上夜、夜班、下夜、休息」。21 日 22:10 出发，上 22 日零点夜班；23 日 08:00 下夜，当晚不再安排夜班车。**二维码仍保存原表 AAONNO，不额外新增夜班。**跨月和跨年也按实际相邻日期判断，缺少下一天排班时不猜测最后一个夜班。

升级请直接覆盖安装 v1.7，**不要卸载旧版**，以保留本机调整。从 v1.0 升级时会保留排班并暂停旧版闹钟，请进入提醒设置核对后重新开启；从 v1.1 / v1.2 / v1.3 / v1.4 / v1.5 / v1.6 覆盖升级会保留现有作息和提醒开关。重新测试响铃。开发包不等同于已在应用商店发布。

Android 响铃通过系统 AlarmManager 定时触发前台音频服务，使用闹钟音量，持续响铃与振动，支持停止和延后 10 分钟，最多响铃 5 分钟。系统可限制锁屏全屏显示、电池后台活动、勿扰模式或音量；需检查手机设置。不依赖网页常驻或互联网。完整计划保存在本机，系统同时安排最近 64 条，触发或重启后补齐，避免全年多重闹钟超过手机厂商限制。关闭提醒会取消已安排的闹钟。网页不承诺关闭后的后台提醒，提供含 `VALARM` 的 `.ics` 导出作为替代，导入后需在系统日历中确认实际提醒。

数据保存在本机应用存储 / 浏览器 localStorage，不上传服务器。清除应用数据或卸载会丢失本机调整，请通过二维码或文本备份。二维码包含排班，请仅与需要的人分享。

## 开发

需要 Node.js 22+。在仓库根目录执行：

```sh
npm ci --cache /workspace/.cache/npm
npm run dev
npm test
npm run build
```

网页开发端口默认 5173，开发服务器监听所有网卡。摄像头需要 HTTPS 或受信任的本机环境；安卓安装版直接使用原生 WebView 权限。生产资源在 `dist/`。

## 构建 Android APK

需要 JDK 21、Android SDK 36、Build Tools 35、网络访问 Google Android / Maven 与 Gradle。标准 Android Studio 也能打开 `android/` 工程。云环境命令：

```sh
python scripts/setup-android.py
python scripts/build-android.py
```

SDK、Gradle、npm 缓存位于 `/workspace` 的仓库外目录。安装器校验官方 Android 工具校验和；Gradle wrapper 校验官方 SHA-256。不会关闭 TLS 或包完整性检查。`build-android.py` 从当前平台的代理环境配置 Java 网络，不复制认证凭据。开发 APK 仅供安装测试；应用商店发布需独立的正式签名和发布流程，不要提交签名私钥。
