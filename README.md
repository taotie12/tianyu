# 值日 · 三值倒班日历

为安卓手机制作的个人倒班日历，同时提供浏览器版本。内置用户上传的《二号机组倒班表》三值实际排班：2025-12-01 至 2026-12-31，共 396 天。逐日提取，不用周期外推。未包含原表中的人员姓名。

## 安装包下载

[下载安卓测试版 APK](downloads/sanzhi-calendar-v1.2.apk)（进入文件页后点击下载按钮）。[原 Excel 的三值排班二维码](docs/三值排班二维码.png)及[AI 生成格式和提示词](docs/二维码导入协议.md)也已随项目提供。

## 使用

1. 安装 `releases/值日-三值-v1.2.apk`（开发测试签名）；也可运行网页版。
2. 早班 08:00–16:00，中班 16:00–次日00:00，夜班 00:00–08:00。作息已按使用者提供的信息预设；在「提醒」核对起床与班车安排后再开启。培训时间未提供，默认不安排培训闹钟。
3. Android 允许通知、精确闹钟、锁屏显示，以及电池设置中的后台运行，再开启上班提醒。点击「测试闹钟」，5 秒后应响铃。正式使用前请在自己的手机上测试锁屏、后台、重启后的提醒。不要强行停止应用。
4. 底部「导入」（桌面版也可用右上角菜单）可打开相机、识别相册二维码、粘贴 SZ1 文本或直接选择同布局的 `.xlsx`。先预览天数、日期及冲突，再确认覆盖。未覆盖日期保持原样。
5. 首次使用会显示「AI 排班二维码」提示，点击「已阅读」后隐藏并记住状态。之后从右上角三横线菜单打开「AI 二维码导入教程」，仍可复制提示词、查看步骤和演示二维码。同一部手机可从相册导入，SZ1 文字也能粘贴导入。

## v1.2 简洁首页

首页上方重复的分享、扫码按钮已移除，手机底部保留日历、导入、提醒、分享。首次提示需点击「已阅读」确认，未确认时再次打开仍会保留，确认后关闭和重开都不会再次显示。右上角三横线菜单可随时重看教程；教程底部也可确认已阅读。已读状态与排班、作息分开保存，不会改动闹钟设置。

## 作息与夜班说明

| 班次 | 实际工作时间 | 默认提醒 |
| --- | --- | --- |
| 早班 | 08:00–16:00 | 06:40 起床；07:00 提醒赶 07:10 班车 |
| 中班 | 16:00–次日00:00 | 15:00 提醒赶 15:10 班车 |
| 夜班 | 00:00–08:00 | **前一晚22:00** 提醒赶 **22:10** 班车 |

班车提前量默认 10 分钟，可调整。起床、班车、额外上班前提醒可独立开关，默认不添加重复的上班前提醒。培训需要另行核对时间和开启。

例如 10 月 19–24 日原表为「中、中、休、夜、夜、休」，日历显示「中、中、上夜、夜班、下夜、休息」。21 日 22:10 出发，上 22 日零点夜班；23 日 08:00 下夜，当晚不再安排夜班车。**二维码仍保存原表 AAONNO，不额外新增夜班。**跨月和跨年也按实际相邻日期判断，缺少下一天排班时不猜测最后一个夜班。

升级请直接覆盖安装 v1.2，**不要卸载旧版**，以保留本机调整。从 v1.0 升级时会保留排班并暂停旧版闹钟，请进入提醒设置核对后重新开启；从 v1.1 覆盖升级会保留现有作息和提醒开关。重新测试响铃。开发包不等同于已在应用商店发布。

Android 响铃通过系统 AlarmManager 定时触发前台音频服务，使用闹钟音量，持续响铃与振动，支持停止和延后 10 分钟，最多响铃 5 分钟。系统可限制锁屏全屏显示、电池后台活动、勿扰模式或音量；需检查手机设置。不依赖网页常驻或互联网。完整计划保存在本机，系统同时安排最近 64 条，触发或重启后补齐，避免全年多重闹钟超过手机厂商限制。关闭提醒会取消已安排的闹钟。网页不承诺关闭后的后台提醒，提供含 `VALARM` 的 `.ics` 导出作为替代，导入后需在系统日历中确认实际提醒。

数据保存在本机应用存储 / 浏览器 localStorage，不上传服务器。清除应用数据或卸载会丢失本机调整，请通过二维码或文本备份。二维码包含排班，请仅与需要的人分享。

## 开发

需要 Node.js 22+。在仓库根目录执行：

```sh
npm ci --cache /workspace/.cache/npm
npm run dev
npm test
npm run build
```

网页开发端口默认 5173，开发服务器监听所有网卡。摄像头需要 HTTPS 或受信任的本机环境；安卓安装版直接使用原生 WebView 权限。生产资源在 `dist/`。

## 构建 Android APK

需要 JDK 21、Android SDK 36、Build Tools 35、网络访问 Google Android / Maven 与 Gradle。标准 Android Studio 也能打开 `android/` 工程。云环境命令：

```sh
python scripts/setup-android.py
python scripts/build-android.py
```

SDK、Gradle、npm 缓存位于 `/workspace` 的仓库外目录。安装器校验官方 Android 工具校验和；Gradle wrapper 校验官方 SHA-256。不会关闭 TLS 或包完整性检查。`build-android.py` 从当前平台的代理环境配置 Java 网络，不复制认证凭据。开发 APK 仅供安装测试；应用商店发布需独立的正式签名和发布流程，不要提交签名私钥。

## 验证

```sh
npm test
npx playwright test
```

浏览器测试需要系统 Chromium（配置默认 `/usr/bin/chromium`），先启动 `npm run dev`。测试覆盖上夜/下夜、跨年班车提醒、起床和班车双闹钟、旧版迁移、AI 教程与示例导入、二维码和 Excel 导入、持久化与手机布局。

可用 `EXCEL_FIXTURE=/绝对路径/倒班表.xlsx npm test` 额外验证上传原表逐日解析结果与内置数据一致。

协议与 AI 提示词见 [二维码导入协议](docs/二维码导入协议.md)。
