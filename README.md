# 值日 · 三值倒班日历

为安卓手机制作的个人倒班日历，同时提供浏览器版本。内置用户上传的《二号机组倒班表》三值实际排班：2025-12-01 至 2026-12-31，共 396 天。逐日提取，不用周期外推。未包含原表中的人员姓名。

## 安装包下载

[下载安卓测试版 APK](downloads/sanzhi-calendar-v1.0.apk)（进入文件页后点击下载按钮）。[原 Excel 的三值排班二维码](docs/三值排班二维码.png)及[AI 生成格式和提示词](docs/二维码导入协议.md)也已随项目提供。

## 使用

1. 安装 `releases/值日-三值-v1.0.apk`（开发测试签名）；也可运行网页版。
2. 在「提醒」中设置并确认早、中、夜、培训的真实上下班时间。Excel 未提供时间，默认值不能当作真实班次时间。全部日期、时间使用北京时间；夜班日期指开始上班当天。
3. Android 允许通知、精确闹钟、锁屏显示，以及电池设置中的后台运行，再开启上班提醒。点击「测试闹钟」，5 秒后应响铃。正式使用前请在自己的手机上测试锁屏、后台、重启后的提醒。不要强行停止应用。
4. 「扫码导入」可打开相机、识别相册二维码、粘贴 SZ1 文本或直接选择同布局的 `.xlsx`。先预览天数、日期及冲突，再确认覆盖。未覆盖日期保持原样。
5. 「分享排班」可生成本机排班的二维码、保存图片或导出文字，并复制专用 AI 提示词。其他 AI 可按照提示词读取新 Excel、生成相同格式二维码。

Android 响铃通过系统 AlarmManager 定时触发前台音频服务，使用闹钟音量，持续响铃与振动，支持停止和延后 10 分钟，最多响铃 5 分钟。系统可限制锁屏全屏显示、电池后台活动、勿扰模式或音量；需检查手机设置。不依赖网页常驻或互联网。重启后会恢复未来闹钟。关闭提醒会取消已安排的闹钟。网页不承诺关闭后的后台提醒，提供含 `VALARM` 的 `.ics` 导出作为替代，导入后需在系统日历中确认实际提醒。

数据保存在本机应用存储 / 浏览器 localStorage，不上传服务器。清除应用数据或卸载会丢失本机调整，请通过二维码或文本备份。二维码包含排班，请仅与需要的人分享。

## 开发

需要 Node.js 22+。在仓库根目录执行：

```sh
npm ci --cache /workspace/.cache/npm
npm run dev
npm test
npm run build
```

网页开发端口默认 5173，开发服务器监听所有网卡。摄像头需要 HTTPS 或受信任的本机环境；安卓安装版直接使用原生 WebView 权限。生产资源在 `dist/`。

## 构建 Android APK

需要 JDK 21、Android SDK 36、Build Tools 35、网络访问 Google Android / Maven 与 Gradle。标准 Android Studio 也能打开 `android/` 工程。云环境命令：

```sh
python scripts/setup-android.py
python scripts/build-android.py
```

SDK、Gradle、npm 缓存位于 `/workspace` 的仓库外目录。安装器校验官方 Android 工具校验和；Gradle wrapper 校验官方 SHA-256。不会关闭 TLS 或包完整性检查。`build-android.py` 从当前平台的代理环境配置 Java 网络，不复制认证凭据。开发 APK 仅供安装测试；应用商店发布需独立的正式签名和发布流程，不要提交签名私钥。

## 验证

```sh
npm test
npx playwright test
```

浏览器测试需要系统 Chromium（配置默认 `/usr/bin/chromium`），先启动 `npm run dev`。测试覆盖日历、单日调整及持久化、图片二维码导入、错误值组拦截、二维码下载、含闹钟的日历导出和手机布局。

可用 `EXCEL_FIXTURE=/绝对路径/倒班表.xlsx npm test` 额外验证上传原表逐日解析结果与内置数据一致。

协议与 AI 提示词见 [二维码导入协议](docs/二维码导入协议.md)。
