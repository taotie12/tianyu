# 安卓测试版下载

[下载最新版 v1.3 APK](sanzhi-calendar-v1.3.apk)（打开文件页面后点击下载按钮）。

v1.3 修复弹窗滚动：× 固定在右上角，安卓侧滑/返回键优先关闭弹窗；增加锁屏显示、后台弹出、自启动和省电设置向导，以及 30 秒锁屏/后台响铃测试。页面刷新恢复失败时不再清空已有闹钟或自动关闭提醒，保留新设置并等待重试。菜单底部新增「作者：taotie」。

**请直接覆盖安装，不要先卸载旧版。**安装后打开应用，在三横线菜单 →「闹钟权限与后台设置」按顺序开启并核对各项权限。自启动、锁屏显示和后台弹出属于手机厂商权限，应用不能代你开启。点「30 秒后测试锁屏与后台响铃」，返回桌面并锁屏，再测试清理后台、重启后的情况。[详细操作说明](../docs/安卓权限与后台提醒.md)。

v1.1 / v1.2 用户的排班、作息和提醒开关会保留；从 v1.0 升级需要重新核对并开启提醒。原有上夜/下夜、起床/班车提醒和首次 AI 导入教程继续保留。班车默认提前 10 分钟，实际发车时间为 07:10 / 15:10 / 前一晚22:10。

此版本已通过构建和自动化测试；安卓真机的侧滑、锁屏、后台和重启后的响铃仍需在自己的手机验证。系统“强行停止”会阻止闹钟，必须重新打开应用。APK 为开发测试签名，与旧版证书一致。

历史版本：[v1.2](sanzhi-calendar-v1.2.apk)、[v1.1](sanzhi-calendar-v1.1.apk)、[v1.0](sanzhi-calendar-v1.0.apk)。
