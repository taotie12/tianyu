# 安卓测试版下载

[下载最新版 v1.7 APK](sanzhi-calendar-v1.7.apk)（打开文件页面后点击下载按钮）。

v1.7 将桌面小部件改为两种尺寸：**4×2 显示今天起 7 天，2×2 显示今天起 3 天**，均保留上夜、下夜标注。

覆盖安装后打开应用，三横线菜单 →「桌面小部件」→ 选择尺寸 →「添加到桌面」。也可长按桌面 →「小部件 / 窗口小工具」，分别选择「值日 · 7天排班（4×2）」或「值日 · 3天排班（2×2）」。旧 4×3 卡片可长按缩小到两行，或只移除卡片后重新添加，排班保留。

两种尺寸可以同时添加，跟随当前班组同步；删除最后一个班组后清空。移除一种尺寸不会中断另一种的跨天更新。[操作说明](../docs/桌面小部件.md)。

v1.5 新增「三横线菜单 → 管理班组 → 删除」。删除前确认名称；删除其他班组不影响当前提醒。删除当前班组会先取消闹钟，切换剩余班组并关闭提醒，需要时重新开启；取消失败不删除数据。最后一个班组也能删除，重开保持空日历，不自动恢复三值。删除会移除该班组的本机手动修改。

[OT105 一值、五值完整二维码](../docs/ot105-overhaul/README.md)已补入过渡排班，覆盖 2026-10-19 至 2027-02-28，共 133 天。直接重新导入同名大修班组即可，不必先删除。

继续支持一值、二值、三值、四值、五值及其他值别。以前发出的四张二维码直接可用，无需重做。导入后首页、分享和闹钟使用真实值别；各值排班独立保存，标题旁可切换已保存的值，闹钟只提醒当前值。Excel 导入可选择列，AI 教程可选择或填写值别。

保留 v1.3 的修复：× 固定在右上角，安卓侧滑/返回键优先关闭弹窗；增加锁屏显示、后台弹出、自启动和省电设置向导，以及 30 秒锁屏/后台响铃测试。页面刷新恢复失败时不再清空已有闹钟或自动关闭提醒，保留新设置并等待重试。菜单底部新增「作者：taotie」。

**请直接覆盖安装，不要先卸载旧版。**安装后打开应用，在三横线菜单 →「闹钟权限与后台设置」按顺序开启并核对各项权限。自启动、锁屏显示和后台弹出属于手机厂商权限，应用不能代你开启。点「30 秒后测试锁屏与后台响铃」，返回桌面并锁屏，再测试清理后台、重启后的情况。[详细操作说明](../docs/安卓权限与后台提醒.md)。

v1.1 / v1.2 / v1.3 / v1.4 / v1.5 / v1.6 用户的排班、作息和提醒开关会保留；从 v1.0 升级需要重新核对并开启提醒。原有上夜/下夜、起床/班车提醒和首次 AI 导入教程继续保留。班车默认提前 10 分钟，实际发车时间为 07:10 / 15:10 / 前一晚22:10。

此版本已通过构建和自动化测试；安卓真机的桌面添加、尺寸与跨天刷新，以及锁屏、后台和重启后的响铃仍需在自己的手机验证。系统“强行停止”会阻止闹钟，必须重新打开应用。APK 为开发测试签名，与旧版证书一致。
